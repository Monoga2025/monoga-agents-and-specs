# Investigación de clientes

El trabajo empieza con una pregunta falsable y fuentes fechadas. Se entrevista o se observa con permiso; las escenas de la matriz editorial son hipótesis, no testimonios. El investigador entrega observaciones, contraevidencia, incertidumbres y preguntas para validar el costo de la brecha.

No recolectar listas personales, inferir consentimiento de una página pública ni convertir datos históricos de otros negocios en demanda actual. Usar el rol [investigador](../marketing/equipo/investigador.md) y el registro de fuentes de [evidencia y medición](../evidencia-medicion/README.md).
