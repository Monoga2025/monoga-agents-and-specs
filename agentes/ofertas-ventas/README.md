# Ofertas y ventas

Las ofertas iniciales son **pilotos propuestos**. Ningún precio, plazo o resultado ha sido aprobado o validado en clientes. El diseñador de ofertas utiliza la ficha de investigación y devuelve alcance, entregables, exclusiones, dependencias y condición de aceptación para que Daniel decida.

Un piloto documental para contadores evalúa búsqueda y citación de normas públicas. Un diagnóstico de proceso Odoo evalúa datos duplicados y factibilidad técnica. Ambos se describen en la matriz editorial y en el libro. Contacto, cotización, contrato y pago necesitan autorización específica.
