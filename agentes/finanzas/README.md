# Finanzas

La meta reportada de COP 2–3 millones mensuales orienta preguntas de capacidad, no fija un precio. La cifra de ingresos web reportada por Daniel tampoco valida ingresos futuros de servicios de IA.

Para estimar el costo de un proceso sin resolver, recoger horas observadas, costo por hora, ciclos, horas de reproceso y costos directos documentados. La fórmula de escenario es `horas × costo/hora × ciclos + reproceso × costo/hora + costos directos`. Si un dato falta, el resultado queda pendiente; una cifra hipotética debe rotularse como escenario, nunca como pérdida real. El rol de [economía unitaria](../marketing/equipo/economia-unitaria.md) prepara la ficha para revisión de Daniel.
