# Entrega de IA

## Consulta documental en profesiones

Partir de documentos oficiales públicos identificados por URL y fecha. Una demostración con NotebookLM puede mostrar consultas y referencias, pero cada respuesta requiere abrir el documento original, comprobar modificaciones y confirmar pertinencia con el profesional. La herramienta no sustituye el juicio contable o legal y no promete actualizar por sí sola la normativa pública.

## Procesos de empresa y Odoo

Primero mapear evento, origen, destino, dueño del dato y excepción; después comprobar versión, edición, plan, permisos y entorno de prueba. La [API externa JSON-2 de Odoo 19](https://www.odoo.com/documentation/19.0/developer/reference/external_api.html) está documentada para el plan Custom; ese dato no confirma la elegibilidad de una instancia concreta. No pedir claves ni acceder a una cuenta para preparar el diagnóstico local.

Salida de cualquier piloto: evidencia de pruebas, casos fallidos, responsable de revisión, aceptación o bloqueo. Los roles especializados están en `marketing/equipo` para mantener una sola biblioteca de instrucciones.
