# Evidencia y medición

`datos/editorial.json` es la fuente editable. `generar.mjs` produce el libro Excel y el muro HTML local. Para actualizar mensajes, cambie primero los datos y vuelva a generar las dos salidas. El libro ayuda a leer y ordenar; el muro permite revisar los diez estados editoriales de dos perfiles y los guiones sin conectarse a un servicio.

Cada fila conserva identificador, fuente, fecha, estado y pregunta de validación. Una cita demuestra que una página dijo algo en la fecha de consulta; no demuestra que una norma aún aplica, que un cliente sufre el problema, que Odoo está habilitado ni que un mensaje convierte.

La escala 0–100 se divide en cinco tramos: 0–19 problema todavía difuso; 20–39 problema identificado; 40–59 exploración de mecanismos; 60–79 evaluación de opciones; 80–100 decisión de un piloto. Son posiciones de contenido, no diagnósticos de audiencia.
