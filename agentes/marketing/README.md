# Marketing propio

El equipo explica cómo una profesión o empresa podría aplicar IA a un proceso concreto. Los videos son un canal de comunicación de Monoga. No se venden servicios de edición audiovisual desde esta arquitectura.

## Cadena de producción

| Paso | Rol | Entrega |
| --- | --- | --- |
| 1 | Investigador | Evidencia y preguntas pendientes |
| 2 | Planificador | Audiencia, nivel editorial y objetivo |
| 3 | Crítico | Riesgos de afirmación, claridad y empatía |
| 4 | Planificador | Revisa el plan ante hallazgos concretos; hasta dos pases de crítica |
| 5 | Estratega | Ángulo y propuesta de mensaje |
| 6 | Guionista AIDA | Guion con atención, interés, deseo y acción |
| 7 | Editor | Lenguaje preciso y ritmo |
| 8 | Visuales | Plano y ayudas visuales accesibles |
| 9 | Verificador de evidencia | Citas, vigencia, alcance y límites |
| 10 | Orquestador | Control de fuentes y entrega a Daniel |

El flujo sigue el archivo del orquestador: investigador → planificador → crítico → revisión concreta del plan por el planificador → estratega → guionista → editor → visuales → verificador de evidencia → orquestador. El segundo pase de crítica solo se usa si persiste un hallazgo material. Si falta evidencia para una afirmación, cambia a condicional o la retira. 
Los [dos borradores iniciales](borradores/README.md) están listos para lectura humana, no para publicar.
